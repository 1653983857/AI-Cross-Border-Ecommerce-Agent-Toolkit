# 基金投资决策技能

统一入口：`$investment-decision`，界面名称“基金投资决策”。

覆盖国内主动/股票/混合/指数/债券/货币基金、ETF/LOF、QDII、FOF、REITs，以及海外基金和ETF。个股研究用于持仓穿透及用户明确的个股任务。实际可购买范围由你的账户、所在地与产品规则决定。

目标：在你的资金用途、投资期限和风险预算内，提高扣费后的长期财富增长。输出本阶段投入/退出金额、每只基金的目标金额与比例、买入/卖出/持有判断、今日可执行和待到账后的金额，以及依据、情景损失和调整条件。

## 开始使用

安装后在下一轮对话直接说：

> 使用 $investment-decision。我主要投资国内基金和海外资产基金。请先了解我的资金和持仓，再分析当前阶段该买、卖还是持有，给出具体支付金额、目标仓位和调整条件。

首次需要：

1. 可用现金与完整持仓（基金代码/份额、金额、可卖份额、买入时间或赎回费用）。
2. 必须保留的应急资金、近期用钱计划。
3. 投资期限、能够承担的损失。
4. 可购买渠道/账户，是否能直接买海外基金；影响准入和税费时需补充居住与税收身份。

持仓表可以提供在聊天中或本地文件中。真实资金资料保留在当前任务的本地工作目录，不上传公共代码仓库。技能会核实当期数据、产品费用和申赎状态；未配置的数据接口不会假装已接通。

## 能力边界

这是会做金额计算的研究与决策辅助技能。可以明确提出买卖或不交易建议，也可以因为数据不足而要求补齐关键输入。它不能证明未来收益最高，不能编造胜率，不能把风险预算当作最大亏损保证；不自动下单。安装也不代表已启动持续监控。

五个上游项目以固定版本纳入仓库；本技能内含89份离线参考，只需一个调用入口。第三方原文保留各自许可，其中taxue-invest使用Prosperity限制许可，不能按本仓库MIT许可无限制商用。

源码、算法、输入规范、测试和许可证均在同目录 `investment-decision/`。合成示例只用于验证实现，不是对任何真实基金的建议。
